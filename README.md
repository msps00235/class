# 班級網頁（快樂窩）

給國小老師用的班級網頁：**最新消息、每日聯絡簿（含月曆）、榮譽榜、功課表、隨機格言**。
老師在網頁上輸入密碼就能直接編輯，家長與學生打開網址永遠看到最新內容。手機、電腦都適用。

範例站：<https://msps00235.github.io/class/>

## 功能一覽

| 單元 | 內容 |
|---|---|
| 最新消息 | 標題列表，點開看全文；可置頂、附相關網址、上傳附件（自動存老師的雲端硬碟） |
| 聯絡簿 | 預設顯示「今天」的回家功課與叮嚀；右側月曆可點日期回看任何一天 |
| 榮譽榜 | 一行一筆（姓名＋事蹟），可自訂日期 |
| 功課表 | 固定顯示在右側的迷你課表，滑鼠移過（手機點標題）放大成完整課表；科目、顏色、節次全部可自訂 |
| 隨機格言 | 橫幅下方每次隨機顯示一句，格言在獨立的管理頁（quotes.html）維護 |
| 網站設定 | 班級名稱（橫幅標題）、課表小標，都在網頁上改，換班級不用改程式 |

## 架構

```
瀏覽者 ──看──> GitHub Pages（index.html + quotes.html，純靜態網頁，免費）
                    │ 讀取資料 (GET)
                    ▼
          Google Apps Script（老師自己部署，免費）
                    │ 驗證老師密碼後寫入 (POST)
                    ▼
          老師的 Google 雲端硬碟
          class/
          ├─ class-data-default.json   ← 班級資料
          └─ 附件/                      ← 消息附件
```

沒有任何伺服器要租、沒有費用；資料完全在老師自己的 Google 帳號裡。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 班級網頁主頁（全部功能都在這一個檔案裡） |
| `quotes.html` | 格言管理頁（老師登入後新增／修改／刪除格言） |
| `apps-script.gs` | 後端程式，貼到 Google Apps Script 部署 |

# 新老師 Setup 教學（從零開始，約 20 分鐘）

想架自己班網的老師，照以下四步驟做一次即可，之後日常更新都直接在網頁上操作。

## 第一步：部署 Google Apps Script（資料後端）

1. 用**自己的 Google 帳號**打開 <https://script.google.com> → 「新專案」
2. 刪掉編輯器裡的預設內容，把本專案 `apps-script.gs` 的內容**全部**貼上
3. **按儲存**（磁碟片圖示或 Ctrl+S / ⌘+S）←很容易漏掉
4. 上方函式下拉選單選 **初次設定** → 按「執行」→ 依提示授權（會要求存取雲端硬碟）
   （這一步把老師密碼初始化為 `happy404`）
5. 右上角「部署」→「新增部署作業」→ 類型選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**任何人** ←注意不是「任何擁有 Google 帳戶的使用者」
6. 按「部署」，複製產生的**網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`）

> ⚠️ 若用學校配發的 Google Workspace 帳號，有些學校會禁止開放外部存取或公開共用檔案；
> 遇到問題請改用個人 Gmail 帳號重做一次。

## 第二步：把網址填進兩個網頁檔

用文字編輯器打開 `index.html` 和 `quotes.html`，各找到這一行：

```js
var API_URL = '…';
```

把引號中的內容換成你第一步複製的網址。兩個檔案都要改。

（選擇性：`quotes.html` 裡的 `DEFAULT_QUOTES` 是預設格言清單，可自行增刪；
`index.html` 內嵌的範例班級資料不用動，上線後在網頁上改成自己的即可。）

## 第三步：上架 GitHub Pages（網頁主機）

1. 註冊／登入 GitHub，建立一個**公開（Public）**儲存庫，例如 `class`
2. 上傳 `index.html`、`quotes.html`（`apps-script.gs` 和本 README 可一併上傳當備份）
3. 儲存庫 **Settings → Pages** → Branch 選 `main`、資料夾 `/ (root)` → Save
4. 約一分鐘後網址生效：`https://<你的帳號>.github.io/class/`

## 第四步：第一次使用（初始化）

1. 打開網址，捲到最下面點「🔑 老師專區」，用密碼 `happy404` 登入
2. **馬上點「修改密碼」換成自己的**（會同步更新後端驗證）
3. 點「網站設定」把班級名稱改成自己的班
4. 隨便按一次儲存後，資料檔會自動出現在你雲端硬碟的 `class` 資料夾
5. 打開 `你的網址/quotes.html` 登入一次，預設格言會自動存入資料庫
6. 把範例的消息、聯絡簿、榮譽榜刪掉換成自己的，課表點「編輯課表」改

完成！把網址發給家長吧。

# 日常使用

- **更新內容**：打開網頁 → 老師專區登入 → 各單元的「＋新增／編輯／刪除」按鈕，儲存即發布
- **課表**：放大課表裡點「編輯課表」；點科目名稱再點格子可快速填入；「＋新增科目」自訂科目與顏色
- **格言**：老師模式工具列的「格言管理」，一行一句可大量貼上
- **附件**：新增消息時直接選檔上傳（單檔 15MB 以內），會自動存到雲端硬碟並設成「知道連結的人可檢視」

# 常見問題

- **忘記老師密碼**：到 Apps Script 專案 →（左側齒輪）專案設定 → 指令碼屬性，`TEACHER_PW` 的值就是目前密碼，也可直接在那裡改
- **換班級／新學年**：網址和程式都不用動——在網頁上改「網站設定」的班名、刪舊內容、改課表即可
- **改了 Apps Script 程式**：貼上新程式後要「部署 → 管理部署作業 → 編輯 → 新版本 → 部署」才會生效（用編輯現有部署的方式，網址才不會變）
- **要改網頁功能或版面**：改 `index.html` 後上傳到 GitHub 覆蓋，網址不變

# 注意事項

- 網頁內容**任何拿到連結的人都看得到**，請勿放成績、身分證字號、住址等個資
- 老師密碼只是編輯權限的門鎖，不要拿重要帳號的密碼來用
- 資料都在老師自己的雲端硬碟 `class` 資料夾，換電腦、換手機都不影響
